# Arma Reforger Workshop

## Summary

Adds US and USSR saline bags from 250 ml to 1500 ml, including manual interruption and reusable remaining saline in 250 ml steps.

## Description

Expanded Saline Bags adds more flexible fluid-treatment options for US and USSR forces while keeping the vanilla 750 ml saline bag fully supported.

### Features

- Saline bags in 250 ml, 500 ml, 750 ml, 1000 ml, 1250 ml, and 1500 ml sizes
- Matching US and USSR variants available in their faction arsenals
- Medical regeneration values matched to each bag's stated volume
- Manual interruption with **Stop saline** / **Saline stoppen**
- Three-second held interaction using the native progress circle
- Remaining saline rounded down to the nearest full 250 ml and returned as the matching faction bag
- Remaining bag placed at the user's position if their inventory is full
- Multiplayer and dedicated-server support

The 750 ml bags are the original Arma Reforger items. This mod adds the other five sizes for each faction.

Amounts below 250 ml are discarded when an infusion is stopped. The mod requires only Arma Reforger and has no ACE dependency. ACE Medical compatibility has not yet been verified.

Core functionality, manual interruption, progress handling, and remaining-volume handling have been tested successfully in multiplayer and on a dedicated server.
